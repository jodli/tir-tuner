tir-tuner: verification report

Every number on the medical path, where it comes from, and what checks it. Generated by tools/gen_verification_report.py from the sources the gates read; it lists the checks, it doesn't run them. For the plain-language version see the patient pages.

  • 70 claims in docs/sources.toml, each tied to a source.
  • 18 medical files with 105 consts and 76 tests. The lint test tir-tuner-common/tests/sources.rs fails when a number in these files doesn't trace to a claim.
  • Mutation gate on the same files.
  • 15 Kani proofs in 4 crates.
  • Fuzz targets.

Claims by source

70 claims: 43 source, 14 derived, 10 assumption, 3 user. The statuses are defined at the top of docs/sources.toml.
